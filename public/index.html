📖 ขั้นตอนการเชื่อมต่อ Google Sheets เป็นฐานข้อมูล

ขั้นตอนที่ 1: สร้าง Google Sheets ใหม่
1. เข้าไปที่ sheets.new เพื่อสร้างไฟล์ Google Sheets ใหม่
2. ตั้งชื่อไฟล์ตามต้องการ เช่น MC_OF_ISKKU_2026_DATABASE
ขั้นตอนที่ 2: เปิด Apps Script และวางโค้ด
1. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
2. ลบโค้ดเดิมในไฟล์ Code.gs ออกทั้งหมด
3. กดปุ่ม "📋 คัดลอกโค้ด Code.gs" ด้านล่างเพื่อคัดลอกโค้ด แล้วนำไปวางในหน้าต่าง Apps Script
ขั้นตอนที่ 3: ทำให้ใช้งานเป็นเว็บแอป (Deploy as Web App)
1. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การเปิดตัวใช้งานใหม่ (New Deployment)
2. เลือกประเภทเป็น เว็บแอป (Web App)
3. กำหนดค่า:
  • การเข้าถึงในฐานะ (Execute as): ฉัน (Me)
  • ผู้มีสิทธิ์เข้าถึง (Who has access): ทุกคน (Anyone)
4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) แล้วกดให้สิทธิ์การเข้าถึง (Grant Permissions)
5. คัดลอก URL เว็บแอป (Web App URL) ที่ขึ้นต้นด้วย https://script.google.com/macros/s/.../exec
ขั้นตอนที่ 4: วาง URL ในระบบ
นำ Web App URL มาวางในช่อง Google Apps Script Web App URL บนหน้าเว็บ แล้วกดปุ่ม "💾 บันทึก URL" จากนั้นกด "⚡ ซิงค์ข้อมูลทั้งหมดไป Google Sheets" ระบบจะสร้างตารางและซิงค์ข้อมูลให้อัตโนมัติ!
